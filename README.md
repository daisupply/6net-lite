# 6net lite ✦

the lite cut of 6ixnetworks — just the good stuff, nothing else.

**inside:** search (real browser tabs, ultraviolet + wisp) · games (8,000+ catalog + a built-in retro emulator) · apps · 6ixtube

**not inside:** ai, accounts, chat, movies, tracking. there is nothing to sign up for.

## run it

```bash
npm install
node server.js   # http://localhost:8080
```

one node server does the whole thing.
